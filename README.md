# TestNetworkConnection

A PowerShell tool for collecting Windows system and network information
and performing basic network diagnostics.

## Features

- Computer information
- Current user information
- Windows version
- Network adapter information
- Adapter status
- MAC address
- Interface index
- IPv4 address
- Default gateway
- DNS resolution check
- Basic error handling
- Diagnostic report

## Requirements

- Windows 10 or Windows 11
- PowerShell 5.1 or later
